Um iPad de 2012 virou monitor

O iPad 3 está preso no iOS 9 e nenhum app de segundo monitor instala nele. O Tela 2 resolve com HTTP simples, JPEG e JavaScript da época.

Ver o código no GitHub

Três portas fechadas

Comprar um monitor custava mais de R$ 200. Havia um iPad 3 parado na gaveta, com tela boa e Wi-Fi. O problema era fazer o Windows falar com ele.

  • 32 bits, iOS 9.3.6É a última versão que o iPad 3 aceita. Nada novo instala nele.
  • Spacedesk não instalaA App Store diz “não compatível”: o app é só 64 bits.
  • A versão web também falhaO visualizador pelo navegador precisa de WebSocket, e o Safari do iOS 9 dá “não foi possível criar websocket”.

Só o que o Safari antigo entende

Sem WebSocket, sem app, sem jailbreak. O PC manda uma imagem por vez; o iPad pede a próxima assim que a anterior chega, e devolve os toques como cliques.

  └──────────── /toque?a=clique&x=…&y=… ◀──────  toque vira XMLHttpRequest
move e clica o mouse (Win32)

  • Uma imagem por pedido

    O iPad pede /frame.jpg e só pede o próximo quando o anterior aparece. O ritmo se ajusta sozinho ao que o iPad aguenta.

  • Uma conexão só

    Com HTTP/1.1 e keep-alive, o iPad não abre uma conexão TCP nova a cada quadro. No Wi-Fi do iPad 3, isso faz diferença.

  • Toque que não se perde

    A imagem é trocada 17 vezes por segundo, e o iOS perde o gesto se o elemento tocado some. Uma camada fixa transparente recebe os toques.

  • Chave e travas

    Como o toque controla o mouse do PC, imagem e toque exigem uma chave de 6 dígitos. Cinco erros bloqueiam o aparelho por 5 minutos, e o servidor se recusa a usar a tela principal.

O que o iPad 3 aguentou

17,4q/sde média em 1024 × 768, contados pelo servidor.
30minseguidos com imagem, sem congelar.
3gestostocar, arrastar e segurar viram clique, arrasto e botão direito.
0appsinstalados no iPad. Só o Safari e um ícone na Tela de Início.

Medido num iPad 3 (A1430) no Wi-Fi de casa, com o PC no cabo. O atraso ficou baixo na percepção de uso; não foi cronometrado.

Onde ele não chega

  • 15 a 20 quadros por segundo é o teto do iPad 3: vídeo dá para assistir, mas não fica liso.
  • A tela dele é 2048 × 1536; o monitor virtual de 1024 × 768 é ampliado 2×.
  • Vídeos 16:9 ficam com faixas pretas, porque o iPad é 4:3.
  • Sem teclado pelo iPad, sem rolagem com dois dedos.
  • Só Windows, e só na rede de casa: é HTTP sem criptografia. Nada de rede pública marcada como privada, nem porta aberta no roteador.

Para rodar o seu

Precisa de Python 3 e de um driver de monitor virtual, como o Virtual Display Driver. O passo a passo completo, com firewall e resolução, está no README.

pip install -r requirements.txt
python servidor.py

O servidor mostra o endereço com a chave, por exemplo http://192.168.0.10:8080/?chave=123456. Abra no Safari do iPad e adicione à Tela de Início.
